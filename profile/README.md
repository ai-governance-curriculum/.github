## 🎯 Overview

This org covers **AI governance** — *governing, securing and assuring* AI: inventories and risk assessments, red-teaming and adversarial ML, release assurance and evaluation evidence, ML security, agentic safety, enterprise control architecture, and executive leadership of an AI governance program. Every role track has a paired **learning** repository and a **solutions** repository with reference walkthroughs.

**At a glance:**

- 🏢 **20 curriculum repositories** (10 learning + 10 solutions)
- 📚 **10 role tracks**
- 🏛️ Ladder runs from **AI Governance Analyst (L15)** to **Chief AI Officer (L70)**

## 🚀 Quick Start

1. **Choose a track** from the table above, based on your experience and direction.
2. **Clone its repository:**

   ```bash
   git clone https://github.com/ai-governance-curriculum/ai-governance-analyst-learning.git
   cd ai-governance-analyst-learning
   ```

3. **Start with the first module** and read its `README.md`.
4. **Work through the exercises** in each module.
5. **Check the paired solutions repository** for reference walkthroughs.

## 🛠️ Frameworks & Tools Covered

- **Regulation & standards:** EU AI Act, NIST AI RMF, ISO/IEC 42001, SR 11-7
- **Threat frameworks:** OWASP (incl. LLM Top 10), MITRE ATLAS
- **Policy as code:** Open Policy Agent (OPA), Kyverno
- **Supply chain:** Sigstore / Cosign, SLSA
- **Infrastructure & secrets:** HashiCorp Vault, Kubernetes, Terraform, GitHub Actions
- **Explainability:** SHAP
- **Model platforms:** Hugging Face, OpenAI, Anthropic
